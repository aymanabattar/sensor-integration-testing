# Device Readings Dashboard

A standalone test dashboard for viewing device sensor readings, backed by Supabase (Postgres + RPC functions, no custom server) and deployed as a static site. This project has **no dependency on the BinTracker monorepo** — only visual theme token *values* were referenced from it, no code or components. See [`SETUP.md`](SETUP.md) to stand up a fresh copy, and [`DEPLOY.md`](DEPLOY.md) for how it's hosted.
